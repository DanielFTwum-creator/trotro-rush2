# App Icons Generation Guide: Trotro Rush
**Document ID:** TUC-DOC-ICO-2026-001  
**Institution:** Techbridge University College (TUC), Oyibi, Ghana  
**Engineer:** Daniel Twum, Head of ICT  

---

## 1. Icon Specifications
- **Design:** Ghanaian Trotro Minibus in yellow and white livery with national flag ribbon stripe, rooftop luggage rack, and forward traffic navigation arrow.
- **Android Adaptive Icon Canvas:** 108 x 108 dp with safe zone within 66 dp.
- **Background Layer:** `#0F172A` to `#1E3A8A` linear gradient with subtle parking lines.

## 2. Density Placements
- `mipmap-mdpi`: 48 x 48 px
- `mipmap-hdpi`: 72 x 72 px
- `mipmap-xhdpi`: 96 x 96 px
- `mipmap-xxhdpi`: 144 x 144 px
- `mipmap-xxxhdpi`: 192 x 192 px
- `mipmap-anydpi-v26`: Adaptive vector XML (`ic_launcher.xml` and `ic_launcher_round.xml`)
- Google Play Store High-Res Icon: 512 x 512 px PNG, 32-bit with alpha, no rounded corners.
- iOS App Store Icon: 1024 x 1024 px PNG, square, no alpha.
